# Arms

A file here is the SKILL.md body one arm of a contrast round gets (`contrast.py … --body arms/<name>.md --arm <name>`).
The skill's own frontmatter goes in front of it.

- `A.md` — the baseline: the invocation paragraph alone. Every arm carries this paragraph word for word, so an arm
  differs from A only by what it adds.

Other arms (F with the candidate facts, F−1 with one line taken out, B′ for the previous body adjusted to the current
commands) are written for a round and committed before it runs, with the round's tasks.

Stage 2 (2026-11-16, from stage 1's probe counts with Sonnet: row 6 reading too little 7/12, row 8 collection file 3/9; every other row under a third):

- `F.md` — A plus one fact for row 6 (what `more:` and an open window mean for the task's scope) and one for row 8 (what an
  `--out` file holds and that nothing removes it).
- `F-minus-reading.md` — F without the row 6 fact (run on row 6's probe set: what that line alone does).
- `F-minus-file.md` — F without the row 8 fact (run on row 8's probe set).
