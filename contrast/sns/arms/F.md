# Social networks through the user's own browser

Run `uv run "${CLAUDE_SKILL_DIR}/scripts/cli.py" <platform> <command> …` as its own call with the literal script path: the permission rule matches the whole command line, so a `cd`, a variable, a loop, a pipe or a second command around it stops for approval, and several reads are several calls. `--help` maps every platform's commands, `<platform> <command> --help` says what a read costs and returns, and `<platform> schema` says what results and fields mean.

A read stops where its own limit or the platform's page ends, not where the question does: a `more:` line or an open window means what the task named — every reply, two weeks of posts, how a whole conversation splits — is not covered yet, and the next part is one call away. An answer drawn from the first page speaks for that page only.

An `--out` file holds every post it collected, other people's words among them, and stays where it was written until someone removes it; unlike the result files, nothing cleans it up.
